摘要(中文翻译)

低秩适配(LoRA)在监督微调(SFT)和强化学习(RL)中都被广泛使用,而且常常采用相近的优化器设置。然而,这两个阶段的不同动力学如何体现在 LoRA 所优化的低秩增量上,目前仍不清楚。我们在数学推理任务上跟踪 LoRA 更新的奇异谱和子空间,发现 RL 在每个学习率下都使谱集中,而 SFT 在中等学习率下使谱展开;此外,在小学习率下 RL 使奇异子空间旋转得比 SFT 快得多。通过逐个成分地在 SFT 与 RL 之间插值,我们定位出 group-mean baseline 相减是这两种差异的来源。一个通过 LoRA 更新的二次多指标模型揭示了其背后的机制:group-mean baseline 相减使两种相互竞争的力(相干拟合与梯度噪声)之间的平衡倾向于谱集中和更快的子空间旋转,同时迫使有利于风险的学习率变低。在这些动力学的指导下,我们为每个阶段定制 LoRA 更新:在 SFT 中,我们压平完整更新的谱,使适配分散到各个奇异方向;在 RL 中,我们压平处于当前 LoRA 增量张成空间之外的那部分更新,以促进子空间旋转。在多个模型上的数学推理实验表明,对应于 SFT 和 RL 的配置在大多数评估设置中取得了所比较方法中的最佳表现。

结论(中文翻译)

在这项工作中,我们识别出 LoRA 在 SFT 和 RL 下不同的谱与子空间动力学。我们的实验表明,在所考察的各个学习率下,RL 的有效秩持续下降;而对于从 SFT 中受益的模型,在中等学习率下,有效秩的增长伴随着更好的 SFT 表现。除了谱动力学上的这种差异之外,在小学习率下 RL 表现出比 SFT 更快的子空间旋转,且这种差距随着学习率增大而缩小。受控对比表明,group-mean baseline 相减是这些差异的一个关键来源。借助多指标模型,我们的理论框架分析了 baseline 相减如何改变相干拟合与来自梯度噪声的反馈,二者共同决定有效秩、子空间旋转以及预测风险中的学习率偏好。这些见解指导我们选择两种针对 LoRA 优化的动力学启发配置,分别适配 SFT 和 RL 不同的训练动力学。这两种配置在大多数评估设置中都取得了所报告的最高平均准确率。

2. Scaling Laws For Data-Constrained Dense Retrieval

Scaling学习曲线数据受限检索表示相似度(CKA)
2. 作者与机构Bowen Fu, Jingtao Zhan
清华大学深圳国际研究生院;西安交通大学
4. 一句话总结在数据受限(监督数据有限、被反复使用)的稠密检索微调里,用「最小可达评测损失 MAEL」作为目标,35 个 BERT 系模型显示 MAEL 对非嵌入参数量和独立样本数服从简单的乘积幂律,优于常见的加和形式。
5. 为什么重要标准 scaling law 假设数据充足、只训一轮,而微调阶段数据稀缺并被多轮重复使用。这篇把「最优可达损失」与优化轨迹分开:学习率只改变轨迹,不改变最终能到达的 MAEL,横轴按步数重标度后不同学习率的学习曲线重合,CKA 也显示达到 MAEL 的各 checkpoint 学到高度相似的表示。这给「scaling 拟合应该拟合什么量」提供了一个干净的例子。

摘要(中文翻译)

稠密检索模型通常通过在监督检索数据上微调预训练语言模型得到,而高质量标注或交互日志往往有限,并在许多轮次中被反复使用。这种数据受限的情形不同于标准 scaling law 所假设的数据充足情形,因此不清楚最佳可达的检索性能如何随模型规模和独立微调数据变化。我们通过最小可达评测损失(MAEL)来研究这个问题,它定义为在固定模型规模和数据预算下训练过程中达到的最低评测损失。我们首先表明,学习率的选择强烈影响优化轨迹,但对最终可达的 MAEL 影响很小:在重新标度优化步数轴后,不同学习率下的学习曲线重合,CKA 分析显示达到 MAEL 的 checkpoint 学到高度相似的表示。随后我们在 MS MARCO 子集上微调了 35 个 BERT 系稠密检索器,发现 MAEL 可以被非嵌入参数量与独立样本数上的一个简单乘积幂律精确描述,优于常用的加和 scaling 形式。我们进一步推导出达到 MAEL 的训练步数的 scaling 律,并表明最优 weight decay 对应近似不变的 EMA 时间尺度,由此得到更低的 MAEL,并在域内和域外基准上获得更强的检索性能。最后,将损失与步数的 scaling 结合起来表明,在我们观察到的区间内,为降低 MAEL,增大预训练模型规模的微调算力效率约为增加独立域内数据的 1.46 倍。

结论(中文翻译)

(第 6 节)本工作研究数据受限微调下稠密检索的 scaling law,即监督检索数据有限且被反复使用的情形。我们引入最小可达评测损失(MAEL),作为在固定模型规模和独立数据预算下所能达到的最佳性能的稳定度量,并表明在 MS MARCO 子集上微调的 35 个 BERT 系稠密检索器中,MAEL 随模型规模和数据预算服从一个简单的 scaling 律。除了作为 scaling 的目标外,MAEL 与各项标准检索指标反映的下游检索效果有很强的相关性。我们还表明,MAEL 的收敛以及 weight decay 的选择可以从训练动力学中预测,从而在数据有限时实现更高效的微调。我们的发现为分配微调资源提供了实用指导:在所研究的区间内,扩大预训练模型规模往往比收集更多域内数据更省算力,而当模型容量受限时,增加独立数据仍是有效策略。更广泛地说,这项工作把 scaling law 分析从预训练扩展到数据稀缺的后训练场景。(其后的附录 A 只是训练细节与超参表,不属于结论,此处不翻译。)

摘要(中文翻译)
